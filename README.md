# ربات تلگرام فروش کانفیگ VPN

ربات کامل فارسی با aiogram 3 و SQLite: عضویت اجباری، پلن‌ها، پرداخت کارت‌به‌کارت، تایید ادمین با صف، کیف پول، دعوت دوستان، پشتیبانی. همه دکمه‌ها شیشه‌ای هستند.

## ساختار فایل‌ها
| فایل | کار |
|---|---|
| `plans.py` | **همه پلن‌ها و قیمت‌ها اینجاست** (فقط همین را برای تغییر قیمت ویرایش کنید) |
| `config.py` | خواندن تنظیمات از `.env` / Variables |
| `bot.py` | شروع ربات |
| `handlers/` | start، shop، payment، admin، fallback |
| `database.py` | دیتابیس SQLite |
| `backup.py` | بکاپ و ریستور خودکار |

## اجرا روی کامپیوتر (اختیاری)
```
pip install -r requirements.txt
cp .env.example .env     # و BOT_TOKEN را داخلش بنویسید
python bot.py
```

## راه‌اندازی روی Railway (بدون کدنویسی)
1. در @BotFather ربات را بسازید و **توکن** را بردارید.
2. ربات را در **هر دو کانال** به‌عنوان **ادمین** اضافه کنید (بدون این کار بررسی عضویت کار نمی‌کند).
3. حساب ادمین (۷۱۲۵۲۷۶۹۷۹) یک بار ربات را `/start` کند تا بتواند برایش پیام بفرستد.
4. فایل‌های این پروژه را در یک مخزن GitHub آپلود کنید (در سایت GitHub: Add file ← Upload files؛ نیازی به دستور git نیست). فایل `.env` را آپلود نکنید.
5. در Railway: New Project ← Deploy from GitHub repo ← همین مخزن.
6. در تب **Variables** این‌ها را اضافه کنید:
   - `BOT_TOKEN` = توکن ربات
   - `ADMIN_ID` = 7125276979
   - `CHANNEL_1` = https://t.me/KanfingAF
   - `CHANNEL_2` = https://t.me/DollarChiFA
7. (پیشنهادی) در Railway یک **Volume** بسازید و Mount Path را `/data` بگذارید تا دیتابیس با دیپلوی پاک نشود.
8. Deploy کنید. در لاگ‌ها باید «ربات شروع به کار کرد» ببینید.

## دیتابیس و بکاپ (مهم)
- ربات هر ۳ ساعت (و ۱۵ ثانیه بعد از هر تایید/رد سفارش) یک فایل بکاپ برای ادمین می‌فرستد و آن را **پین** می‌کند. این پیام‌ها را پاک نکنید.
- اگر هاست دیتابیس را پاک کند، ربات هنگام روشن شدن خودش آخرین بکاپ پین‌شده را بازیابی می‌کند.
- ریستور دستی: فایل `.db` را با کپشن `/restore` برای ربات بفرستید.

## دستورهای ادمین
`/stats` آمار · `/pending` سفارش‌های در انتظار · `/backup` بکاپ فوری · `/cancel` لغو کار جاری · `/skip` رد بدون علت

## نحوه تایید سفارش
دکمه «✅ تایید» ← ربات می‌گوید «کانفیگ یا آیدی را ارسال کنید» ← پیام بعدی شما عیناً (متن/عکس/فایل) برای مشتری ارسال می‌شود. اگر چند سفارش را پشت‌سرهم تایید کنید، به ترتیب (FIFO) یکی‌یکی از شما کانفیگ می‌خواهد. سفارش‌های شارژ بدون نیاز به کانفیگ، مستقیم موجودی را زیاد می‌کنند.

## نکته
قیمت‌های پلن ۶۰ روزه، نامحدود (زمانی) و حجم‌های بالاتر آی‌پی ثابت در `plans.py` **پیش‌فرض تقریبی** هستند؛ قبل از شروع فروش اصلاحشان کنید.
